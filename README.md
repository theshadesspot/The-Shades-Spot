# The Shade Spot — Website

## To preview locally (optional, needs Node.js installed)
npm install
npm run dev

## To go live (recommended path — no coding needed)
1. Create a free GitHub account at github.com
2. Create a new repository, upload all these files (drag and drop on the GitHub website)
3. Go to vercel.com, sign up free, click "Add New Project", import that GitHub repo
4. Vercel auto-detects it's a Vite project and builds it — just click Deploy
5. In Vercel project settings → Domains, add your purchased domain and follow the DNS instructions shown
